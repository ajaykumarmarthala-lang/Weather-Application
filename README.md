# 🌦️ Weather Application

## 📌 About the Project
The Weather Application is a web-based project developed using HTML, CSS, and JavaScript. It uses a weather API to retrieve live weather information and display it through a simple, user-friendly interface.

## ✨ Features
- Fetch live weather data using a weather API
- Display weather information for a selected location
- Simple and user-friendly interface
- Interactive functionality using JavaScript

## 🛠️ Technologies Used
- **HTML5** – Structures the application
- **CSS3** – Styles the user interface
- **JavaScript** – Handles application logic and API requests
- **Weather API** – Retrieves live weather information

## 🚀 How to Run the Project
1. Clone this repository:
   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```
2. Open the project folder.
3. Open `index.html` in your browser.
4. Search for a location to view its weather information.
